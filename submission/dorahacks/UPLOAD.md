# How to submit on DoraHacks

1. Upload the video to YouTube (`umbra-landscape-1920x1080.mp4`; see `video/YOUTUBE.md`).
2. Open `DESCRIPTION.md` and replace both `[YOUTUBE_LINK]` placeholders with the video's URL.
3. Select everything in `DESCRIPTION.md` and paste it into the BUIDL description editor.

The ten images are hosted in the public repo (https://github.com/drained69/umbra) and are linked
by commit, so they appear automatically when the Markdown is pasted — no uploads needed. The
files are also in `images/` if the form asks for a separate cover or logo (`01-cover.png`).
