# How to submit on DoraHacks

Everything is filled in: the YouTube link, the GitHub link and the ten hosted images.

1. Select everything in `DESCRIPTION.md` and paste it into the BUIDL description editor.
2. The sidebar links (GitHub, YouTube, website) are set separately in the form, so nothing else
   needs editing. Click Create when you are happy with the preview.

The images are hosted in the public repo (https://github.com/drained69/umbra), linked by commit,
so they appear automatically when the Markdown is pasted. `01-cover.png` is also available in
`images/` if you want it as a cover image.
