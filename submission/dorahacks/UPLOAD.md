# How to submit on DoraHacks

1. Open `DESCRIPTION.md`, select everything, and paste it into the BUIDL description editor.
2. Replace the two placeholders:
   - `[YOUTUBE_LINK]` (appears twice) — your YouTube video URL
   - `[GITHUB_LINK]` — your public repository URL
3. Wherever a line says `🖼️ Upload image here: <file>`, put the cursor on that line, click the
   image button in the toolbar, upload that file from `images/`, then delete the placeholder line.
